NANNY MANAGEMENT SYSTEM SETUP GUIDE

1. Install WAMP/XAMPP.
2. Copy the project folder into htdocs or www.
3. Open phpMyAdmin.
4. Create a database called nanny_management.
5. Import sql/schema.sql.
6. Run localhost/nanny_management_system
